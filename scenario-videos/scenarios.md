# Cyber Challenge — Scenario Clips (one per question)

Workflow: generate each keyframe image in ChatGPT (free) → save them in
`scenario-videos/keyframes/` as `q01.png` … `q22.png` and `k01.png` … `k10.png`
→ Claude animates each into a 5s clip with Higgsfield Seedance (≈17.5 credits each at 720p).

---

## How to prompt ChatGPT

For EVERY image, paste the **style block** below + the per-question **prompt**, and
**attach the reference image** (`Downloads/ -11.jpg`, the man reading the letter) every time
so the character and art style stay consistent.

### STYLE BLOCK (paste with every prompt)

> Flat 2D vector cartoon illustration matching the attached reference image exactly:
> bold clean shapes, minimal flat shading, large expressive cartoon eyes, dramatic
> single-source lighting, moody teal-green palette with warm amber accents.
> Main character: an Emirati man in his mid-30s, white kandura, red-and-white
> checkered ghutra with black agal, trimmed goatee, thick expressive eyebrows —
> the SAME man as in the reference image. Portrait 9:16. Cinematic composition.
> NO text, letters, or numbers anywhere in the image (screens show abstract shapes only).

For the **kids' questions (K1–K10)** swap the character line for:

> Main character: an Emirati boy, around 10 years old, white kandura and small white
> ghafiya cap, big friendly expressive eyes — same flat cartoon style as the reference.

Why no text in images: AI garbles Arabic/English text, and the game is bilingual —
clips must work for both languages.

## Production notes

- **Aspect:** 9:16 portrait (matches reference + mobile play page). If these will sit in a
  16:9 area on the live/desktop screen, tell ChatGPT "landscape 16:9" instead — decide
  BEFORE generating all 32.
- **Q6 is free** — the reference image itself is its keyframe and the test clip already exists.
- **Consistency tips for ChatGPT:** always attach the reference image; generate all images
  in ONE chat session; if the character drifts, say "same man as the first image".
- **Animation budget (Higgsfield Seedance 2.0, 5s each):**
  - 1080p standard: 45 credits × 31 ≈ 1,395 (too much)
  - 720p standard: 22.5 × 31 ≈ 700 (too much)
  - **720p fast: 17.5 × 31 ≈ 543** (slightly over the 414.5 balance)
  - **480p fast / Kling Turbo: 7.5 × 31 ≈ 233 (fits easily)**
  - Mixed plan that fits: 720p fast for the 10 kids clips + hero moments, 480p for the rest.
- Filenames when saving keyframes: `q01.png`–`q22.png`, `k01.png`–`k10.png` in
  `scenario-videos/keyframes/`.
